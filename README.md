# Avance del Proyecto Full Stack

Este proyecto lo realicé para mi materia de Desarrollo Full Stack en Tecmilenio.

La idea fue crear una página donde los usuarios puedan iniciar sesión y organizar sus tareas de una manera sencilla.

En la aplicación se pueden agregar tareas nuevas, modificarlas, marcarlas como terminadas y eliminarlas cuando ya no se necesitan.

También trabajé con una base de datos para guardar la información y evitar que las tareas se pierdan al cerrar la página.

Cada usuario tiene sus propias tareas, por lo que no puede ver las de otras personas.

Para realizarlo utilicé HTML, CSS, JavaScript, Node.js y MySQL.

Durante el desarrollo fui haciendo pruebas para comprobar que el inicio de sesión funcionara y que los cambios en las tareas se guardaran correctamente.

Este proyecto me ayudó a entender mejor cómo se conecta una página web con un servidor y una base de datos.
